# Roadster 飞行试玩版 v0.5 状态

记录日期：2026-10-24。四个场景的障碍物造型及随机位置修改已完成，独立 Windows v0.5 已构建并校验。

## 最终行为

城市使用无人机、卫星、带电能量球；沙漠使用不规则岩石、晶簇、风滚草；天空使用雷云闪电、热气球、滑翔机；海底使用水母、水雷、分叉珊瑚。12 种造型具有不同外轮廓，绘制与物理碰撞共用多边形，取消原先所有物体共用的矩形碰撞。描边及吊绳等细装饰提供视觉缓冲。

每组随机选择造型、连续高度、体型和横向偏移，障碍会出现在上、中、下飞行区域。同一造型不会连续重复；随机数发生器在启动时随机化，重试继续使用新的随机序列。前 10 秒保留无障碍练习；60 秒后有 65% 概率产生横向错开的双障碍组。障碍从右侧进入画面，最大造型完整可见后仍有至少 1.5 秒反应时间。

安全通道从 224 收窄至 184 像素；相邻组通道中心最多改变 112 像素，双障碍共享各自组的安全通道。随机大小范围为 78%–100%，必要时缩短高度以保证物体仍在飞行区域内。金币和氮气罐的生成同时检查障碍范围，避免补给出现在障碍物内部。四张菜单场景预览同步更新。

全屏、Esc、音乐、暂停、救援、难度速度曲线及生命规则沿用 v0.4。新素材记录见 [assets-v0.5.md](assets-v0.5.md)。

专项检查使用四个场景、每场景四个固定种子、每种子 180 组，累计 4,420 个障碍。12 种造型均检查实际物理空间中的实体部位与空白角落。随机高度采样的上 / 中 / 下统计分别为：城市 475 / 160 / 470，沙漠 490 / 144 / 471，天空 487 / 144 / 474，海底 488 / 128 / 489。分布带安全约束，不声称全屏均匀采样。所有组的通道、边界、尺寸和相邻变化均通过检查；固定种子可复现，不同种子得到不同路线。

四个场景分别通过 210 秒真实物理与 Input 输入辅助飞行，均无受伤、无救援、无训练期障碍，终点约 8,399.8 米：

路线证据为 builds/qa/v5/route-*.log。QA 控制器参考可见补给及最近障碍组的通道，用普通 Input 喷氮；物理、扣气、碰撞和生命规则全部启用，游戏本身无自动驾驶。最初仅跟随障碍通道的 QA 策略会错过补给，现增加对安全补给路线的优先判断；未为通过测试放宽游戏的燃料或碰撞规则。自动路线证明这些采样路线可玩，不代表所有随机种子均已逐一试玩。

四场景实际 OpenGL 截图及新版菜单已目视检查，造型、补给、HUD 均清楚可见。单独发行 EXE 的窗口及客户区均为 1920 × 1200，与显示器完全一致且无标题栏；正常关闭退出码为 0、stderr 为 0。最终测试、渲染及导出日志无 ERROR / Parse Error / Script Error。尚未进行长期真人手感试玩与实声听音。
