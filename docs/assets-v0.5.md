# v0.5 障碍物素材

2026-10-24。新增障碍由项目脚本直接绘制，无新增外部下载素材。

| 场景 | 专属造型 | 轮廓 |
| --- | --- | --- |
| 霓虹城市 | 无人机、卫星、带电能量球 | 六边机身与旋翼、菱形核心与太阳能翼、放射尖刺 |
| 沙漠 | 岩石、晶簇、风滚草 | 不规则多边形、组合菱形、圆形枝条团 |
| 天空 | 雷云、热气球、滑翔机 | 云团与锯齿闪电、椭圆气囊与吊篮、后掠翼 |
| 海底 | 水母、水雷、珊瑚 | 半圆伞盖与触手、圆形尖刺、分叉轮廓 |

`scripts/hazard_geometry.gd` 统一生成轮廓；`visuals/hazard_visual.gd` 绘制造型与细节；`scripts/hazard.gd` 将相同多边形交给实际物理引擎，透明空白区域不使用矩形填充碰撞。

最大物体宽 110 像素，随机缩放至原尺寸的 78%–100%；高度必要时缩短以留出安全通道。轮廓描边为视觉缓冲，吊篮绳等细装饰不另加伤害范围。无人机旋翼随游戏时钟绘制；暂停时钟冻结。

四张 `assets/previews/*.png` 已由 `tools/generate-previews.gd` 使用正式背景和障碍渲染器重新生成。素材展示截图为 `builds/qa/v5/obstacles-*.png`；截图中的三种造型与高度为便于检查而布置，发行游戏使用随机生成。

车辆、标题、SVG 图标及四首配乐沿用 v0.4 / v0.2。参见 [v0.4 素材](assets-v0.4.md) 与 [v0.2 素材](assets-v0.2.md)。
