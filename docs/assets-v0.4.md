# v0.4 界面素材

本轮使用原生 SVG：

- `assets/ui/speaker-on.svg`：开启音乐的喇叭与声波。
- `assets/ui/speaker-muted.svg`：静音喇叭与红色叉号。
- `assets/ui/coin.svg`：金色圆币与闪电，放在 HUD 和结算金币数字前。

以上图标由项目直接绘制，无图标字体或外部素材依赖。喇叭按钮保留文字悬停提示，显示内容仅为图标。

标题、四场景预览、红心和三角图标延续 [v0.3 素材](assets-v0.3.md)，本轮没有重新生成标题或车辆。银车与四首原创配乐来源见 [v0.2 素材](assets-v0.2.md)。
